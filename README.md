# Phone Tap Counter

A tiny mobile-friendly web app you can run from any phone browser. Tap the big button to count things, and the app saves the count on your device.

## Run it locally

From this folder, start a simple static web server:

```bash
node server.mjs
```

Then open `http://localhost:8000` in a browser.

## Run it on your phone

1. Make sure your computer and phone are on the same Wi-Fi network.
2. Start the server with:

   ```bash
   node server.mjs
   ```

3. Find your computer's local IP address, then open `http://YOUR-IP:8000` on your phone.
4. Optional: use your phone browser's "Add to Home Screen" action for an app-like shortcut.
